# The First Folding Screen Tablet! (@mkbhd, 2020-11-24)

## Summary
Sponsored first look at the $3,000 Lenovo ThinkPad X1 Fold — the world's first foldable-OLED laptop/tablet. He
frames it as **folding-display tech pushed to its size limits, so we can learn where the tech is.** Durable
threads: **the hinge is the hardest part (harder still at laptop scale)**, **a real tactile keyboard still beats
a virtual one** (and Lenovo agrees — they built one), the **foldables-need-developers/apps** bottleneck, and his
**"the more talented people working on foldables, the better they get"** optimism.

## Key claims (paraphrase, dated)
- [2020-11-24] **Pushing the tech to its size limits — a learning device.** "'Folding-display tech is in its
  infancy, so building any machine around it is bleeding edge. **This 13.3" OLED folds to two 9.6" screens —
  it's pushing the tech to its size limits, and from it we can learn a lot about where the tech is right now.**'"
- [2020-11-24] **THE HINGE IS THE HARDEST — even more so at scale.** "'Premium materials (leather wrap, a
  red-felt kickstand — "playing well to my red-and-black habit") — but **the folding screen is the hard part.
  It took Samsung two generations to get the hinge weight right on the tiny Fold; getting it right in a bigger
  laptop takes a lot of engineering and is arguably even more important.**'" Reaffirms the hinge-supremacy
  doctrine at a new scale.
- [2020-11-24] **A REAL KEYBOARD STILL BEATS VIRTUAL — and Lenovo agrees.** "'You can have a virtual keyboard
  with haptics someday, but **there's always something better about a real tactile keyboard — and Lenovo
  basically agrees, because they built an ultra-thin Bluetooth keyboard that magnets onto half the display**
  (near-zero latency, a real trackpad; stores inside when closed).'" A documented tactile-input preference.
- [2020-11-24] **The postures = the point (tablet + laptop, like phone + tablet on the Fold).** "'For Lenovo it's
  about the postures — **the way the Fold is theoretically a phone AND a tablet, this is theoretically both a
  tablet AND a laptop.** My #1 use: **a 13" screen for watching video on a plane tray without a laptop's weight;**
  plus book mode for side-by-side multitasking (Zoom + notes for remote podcasting).'"
- [2020-11-24] **THE OPTIMISM + the developer bottleneck.** "'It's $3,000, not for everyone — but **the upside of
  foldables like this existing is that the more talented people work on making foldable stuff good, the better it
  gets over time.** A big part is **getting developers to make quality apps that take advantage of the folding
  display — still early, not many great ones yet.** The only way to change that is to make good foldable hardware
  and get the ball rolling; then the cycle feeds itself.'" His flywheel view of immature tech.

## Notable verbatim quotes

> engineering to get the hinge weight right in a bigger laptop version."
