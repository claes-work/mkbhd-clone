# MacBook Neo Impressions: Reincarnated!

## Summary

First impressions of the **MacBook Neo** — Apple's new cheapest laptop, a **$599** ($499
with a student discount) 13-inch aluminum machine powered by the **A18 Pro (iPhone) chip**.
Marques frames it as **the old 12-inch MacBook "reincarnated"** — the ultra-portable netbook
Apple couldn't make good with Intel, now finally possible thanks to efficient Apple Silicon.
Its target: **students and education**, where Chromebooks have dominated. Genuinely well-
built for the price, with a few tells (Touch ID only on the 512GB model, a real clicking
trackpad, a merely-okay 500-nit display).

## Key claims

- **[2026-03-04]** The Neo is a **$599** 13" all-aluminum laptop with the **A18 Pro** (a
  binned 5-core-GPU version of the iPhone 16 Pro chip), 8GB/256GB, two USB-C (not
  Thunderbolt), a headphone jack, side-firing stereo speakers, a 1080p webcam (no notch), and
  four colors. **"They actually hit the price"** — now the cheapest Mac laptop, same as the
  Mac mini (which has been "one of the best deals in tech"). (paraphrase + quote)
- **[2026-03-04]** It's for basic tasks (web, email, spreadsheets, light photo/multitasking) —
  "think of it like a Chromebook, but the Apple one… the Safari book." The gatekeeping line:
  **"if you're wondering whether it has enough RAM, or why USB-C and not Thunderbolt — you're
  watching an MKBHD video on upload day, so this probably isn't the computer for you."**
  (quote)
- **[2026-03-04]** Despite the low price it **"doesn't feel cheap"** — "probably the best-built
  laptop at this price" (all-metal, nice hinge). Tells: the **base 256GB has no Touch ID** (just
  a lock button — $100 more gets 512GB + Touch ID); the trackpad is a **real moving/clicking**
  one, not haptic (feels fine); the display is **okay** (13", ~1440p, 60Hz, 500 nits). 16-hour
  quoted battery (vs the Air's 18). (paraphrase)
- **[2026-03-04]** The strategy: give students an **attainable Mac** (the cheapest until now was
  the $1,100 M5 MacBook Air). It undercuts the "cheap laptop or an iPad" alternative — **the base
  iPad ($329) plus its keyboard ($250) is already ~$600 for a 128GB/A16**, so the Neo is "a much
  better value to actually get a Mac." Classic Apple: "would you rather get the thin-and-light
  from Acer, or the one from Apple that works with the iPhone you have?" (paraphrase)
- **[2026-03-04]** **The "reincarnated" thesis**: the original **12-inch MacBook** (~2015) tried
  to be a thinner-than-Air netbook but was hobbled by a throttling 1.1GHz dual-core Intel chip
  (and still cost $1,300) — it was Apple's first USB-C-only laptop. **"Once they spun up Apple
  Silicon, they finally had the ability to make that machine but actually good"** — this is that
  12" MacBook done right. (He extends the theory: the Intel trash-can Mac Pro had the same
  problem, and **the Mac Studio is what it should have been → the Mac Pro is doomed.**) (quote)
- **[2026-03-04]** Also announced that week: a new Studio Display + Studio Display XDR (replacing
  the Pro Display), an **iPhone 17E** (MagSafe, double base storage, pink), spec-bumped M5 Pro/Max
  MacBook Pros, and a spec-bumped M4 iPad Air. (paraphrase)
