# 2024 Tesla Model 3 Performance: 0-60 in 2.9 seconds!

## Summary

Marques's day-one impressions of the refreshed **Tesla Model 3 Performance** (~$60k, 510 hp, 2.9s
0–60). His frame: unlike the Model S Plaid — **"which I had for a long time"** and which is "just a
faster Model S" — the Model 3 Performance is **a more *complete* car**, not just a quicker one (new
rear drive unit, stiffer dampers with matching weight reduction, real sport seats, built-in track
mode). One clear regression annoys him: **the steering-wheel buttons went back to capacitive.** Fully
Marques-narrated; corroborates his Model S Plaid ownership.

## Key claims (biography marked ⬥)

- **[2024-04-23]** ⬥ BIOGRAPHY: **"I had that Plaid for a long time"** — and "there's really not much
  difference between the Model S Plaid and the regular Model S; all they did is make it faster (triple
  motors, carbon-sleeved rotors) — the same brakes, chassis, seats." (Corroborates Model S Plaid
  ownership.) (quote)
- **[2024-04-23]** ⭐ The thesis: the Model 3 Performance **"is not just a mini Model S and faster — they
  did things to make it a more complete car."** A new rear drive unit (rear-biased torque, ~30% more
  peak power across the whole band), stiffer-but-not-harsh dampers offset by weight reduction (same
  mass as before), aluminum pedals, and **genuinely different bolstered sport seats.** The badge reads
  **"insane speed," not Plaid** (Plaid = carbon-sleeved triple motors; "that's why the Cybertruck isn't
  Plaid either — fast dual-motor, no carbon sleeves"). (quote)
- **[2024-04-23]** ⚠️ The regression: **"Tesla finally went to physically clicky steering-wheel buttons
  that we liked — and for some reason this car went BACK to capacitive touch areas. We've been over
  this, this is not what we want. Backwards."** (quote)
- **[2024-04-23]** Built-in **track mode** (over/understeer bias, regen up to 100%, drift/race presets)
  — "a surprising number of Model 3 Performance owners take their cars to the track." Drive: quicker
  across the range, better handling ("even better than the always-nimble Model 3"), ~1,800 kg. (paraphrase)
- **[2024-04-23]** ⭐ The value wrinkle: **"the 'is it worth it' question is funny because the Model S
  Plaid has depreciated so much — isn't it like $80k now? If you specifically want a smaller car, yes,
  this is the one."** "Even if you're in the 'this is soulless, there's no noise' camp — this is a fun
  car." (quote)

## Notable verbatim quotes

- "I had that Plaid for a long time… the Plaid is just a faster Model S. This Model 3 Performance is a more complete car."
- "Tesla finally went to clicky buttons we liked — and this car went back to capacitive. We've been over this. Backwards."
- "Even if you're still in the 'this is soulless' camp — I get it, there's no noise — this is a fun car."
